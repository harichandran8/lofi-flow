LofiFlow Privacy Policy

Last updated: September 21, 2026

Overview

LofiFlow is a Chrome extension that transforms the audio of the user's active browser tab into a lofi-style listening experience using browser audio processing technologies.

Data Processing

LofiFlow processes captured tab audio locally within the user's browser.

LofiFlow does not upload, record, store, sell, or share the captured audio with external servers.

Permissions

LofiFlow uses the following Chrome permissions:

  • activeTab — used to access the user's currently active browser tab after the user interacts with the extension.
  • tabCapture — used to capture audio from the active browser tab so that LofiFlow can process it.
  • offscreen — used to provide the audio processing environment required by the extension.

Information We Collect

LofiFlow does not collect personal information, browsing history, account information, or captured audio.

Third-Party Services

LofiFlow does not send captured audio or user data to third-party servers.

Changes to This Policy

This privacy policy may be updated if the functionality or data practices of LofiFlow change.

Contact

For questions about this privacy policy, please contact the LofiFlow developer through the contact information provided on the Chrome Web Store listing.
